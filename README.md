## Featured project

### [USDC Sepolia Bridge](https://github.com/zerachxyz/usdc-sepolia-bridge)

A testnet interface built with Arc Studio and Circle Bridge Kit for transferring test USDC from **Ethereum Sepolia to Arbitrum Sepolia**.

- Browser-wallet connection and live token balances.
- Amount validation and step-by-step transfer progress.
- Setup instructions and documented limitations.

**Status:** learning prototype; not audited. See the repository for verification details and recovery limitations.
